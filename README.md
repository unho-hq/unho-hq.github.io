# Unho · Albaranes (despliegue)

Página pública de **Albaranes**, la app de albaranes para fontaneros de Unho.

- `index.html`: página de descarga.
- `albaranes/`: la app web compilada (PWA). El código fuente vive en el repositorio privado `unho-hq/unho` (`apps/albaranes`).
- `android/`: envoltorio Android (Trusted Web Activity). El APK lo compila GitHub Actions y lo publica en la release `android`.
